# БУМ Арена

Мултиплейър .io парти игра за браузър (телефон и компютър): чибита се бутат в свиваща се арена.

## Пускане

```bash
npm install
npm run dev        # отвори http://localhost:5173
```

За да играеш от телефон в същата Wi-Fi мрежа, отвори адреса `Network: http://192.168.x.x:5173`, който `npm run dev` изписва.

## Команди

| Команда             | Какво прави                                 |
| ------------------- | ------------------------------------------- |
| `npm run dev`       | dev сървър с презареждане на живо           |
| `npm run build`     | production build в `packages/client/dist`   |
| `npm run test`      | тестове (Vitest)                            |
| `npm run check`     | typecheck + lint + тестове – пусни преди commit |

## Структура

```
packages/
  shared/   логиката на играта (симулация, баланс, ботове) – БЕЗ Phaser
  client/   Phaser 3 клиент: рисуване, ефекти, вход, HUD, преводи
```
