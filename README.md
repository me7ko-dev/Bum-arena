# БУМ Арена

Мултиплейър .io парти игра за браузър (телефон и компютър): чибита се бутат в свиваща се арена.
Печели последният оцелял, а при изтекло време – този с най-много избутвания.

**Текущ етап: 1 – прототип срещу ботове** (един играч + 11 бота, всичко върви в браузъра).

## Пускане

Нужен е Node.js 20+.

```bash
npm install
npm run dev        # отвори http://localhost:5173
```

**От телефон:** телефонът и компютърът трябва да са в една Wi-Fi мрежа. `npm run dev` изписва ред
`Network: http://192.168.x.x:5173`. Отвори този адрес на телефона.

## Управление

| Действие          | Компютър                    | Телефон                                  |
| ----------------- | --------------------------- | ---------------------------------------- |
| Движение          | WASD или стрелки            | докосни където и да е отляво → джойстик  |
| Суперсила (Дъш)   | Space / Shift / J           | големият бутон долу вдясно               |
| Нов рунд          | R (или Enter/Space в края)  | бутон „Нова игра“ / „Пак!“               |
| Без звук          | M                           | бутон ♪ горе вдясно                      |
| Панел за баланса  | ` (клавишът над Tab)        | добави `?tune` към адреса                |

## Настройка на баланса

Всички числа (скорости, сили, замайване, монети, ботове, рунд, свиване на арената) са в
**`packages/shared/src/config/balance.ts`** – всяко с обяснение на български.

Най-бързият начин да намериш „забавната“ настройка:

1. Пусни играта и натисни ` (или отвори `http://.../?tune`).
2. Мести плъзгачите, докато играеш – промените важат веднага (някои – от следващия рунд).
3. „📋 Копирай стойностите“ → постави промените в `balance.ts`.

Визуалната „сочност“ (тресене, hit-stop, искри, сила на звука) е отделно в
`packages/client/src/config/feel.ts` – тя не влияе на играта.

Без браузър: `npm run sim -- 10 12` симулира 10 рунда с 12 бота и печата колко трае рундът,
кой кога пада и кой печели. Полезно след промяна на баланса.

## Команди

| Команда             | Какво прави                                        |
| ------------------- | -------------------------------------------------- |
| `npm run dev`       | dev сървър с презареждане на живо                  |
| `npm run build`     | production build в `packages/client/dist`          |
| `npm run preview`   | пуска production build-а локално                   |
| `npm run test`      | тестове (Vitest)                                   |
| `npm run sim`       | симулация на рундове само с ботове                 |
| `npm run check`     | typecheck + lint + тестове – пусни преди commit    |

Добави `?fps` към адреса, за да виждаш FPS и в production build.

## Архитектура

```
packages/
  shared/            логиката на играта – чист TypeScript, БЕЗ Phaser
    config/balance.ts   всички числа за баланса
    sim/                World: движение, сблъсъци, суперсили, монети, арена, рунд
    bots/               мозък на ботовете
    input.ts            общ формат на входа (клавиатура = джойстик = бот = мрежа)
  client/            Phaser 3 клиент
    game/LocalGame.ts   върти World с фиксирана стъпка (етап 1: в браузъра)
    render/             рисуване и ефекти (частици, тресене, hit-stop)
    scenes/             Boot (генерира текстурите), Game (светът), Hud (интерфейсът)
    input/ ui/ audio/   вход, бутони/джойстик, синтезирани звуци
    locales/            преводи: bg.json, en.json
scripts/sim-bots.ts  симулация без браузър
```

Основни принципи (заради етап 3 – онлайн със сървър):

- **Симулацията е отделна от рисуването.** `World` не знае за Phaser. В етап 3 същият код
  ще върви на Colyseus сървъра, а клиентът ще го ползва за предсказване.
- **Фиксирана стъпка** (30 тика/сек, в конфига); рисуването интерполира между тиковете → плавно на 60+ FPS.
- **Детерминизъм:** само `Rng` със seed, никакъв `Math.random()` в симулацията → рундът може
  да се възпроизведе (бъгове, повторения, клипове от последните 10 сек в етап 6).
- **Събития вместо ефекти:** симулацията казва „удар със сила 0.8 тук“ (`GameEvent`),
  клиентът решава как да го покаже. Ботовете подават същия `PlayerInput` като човека.

Текстовете са само в `locales/*.json` – в кода се ползва `t('ключ')`.
